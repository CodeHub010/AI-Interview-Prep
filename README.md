# 🎙️ AI Interview Preparation Assistant

An interactive AI-powered interview preparation application that helps users practice interview questions, answer using their voice, and receive instant feedback.

## 🚀 Live Demo

👉 [Try the AI Interview Preparation Assistant](https://ai-interview-prep-hkkgjfuyvgdd9tcpjvjwte.streamlit.app/)


## ✨ Features

- 🎯 Interview questions organized by category
- 🔊 Listen to interview questions using Text-to-Speech
- 🎙️ Record answers using your microphone
- 🗣️ Convert spoken answers into text
- 🧠 Automatically evaluate answers
- 📊 Get an interview score
- 💡 Receive instant feedback
- 🔊 Listen to feedback using voice
- 🖥️ Simple and user-friendly Streamlit interface

## 🛠️ Technologies Used

- **Python**
- **Streamlit**
- **SpeechRecognition**
- **Google Speech Recognition**
- **gTTS (Google Text-to-Speech)**
- **JSON**
- **PyTorch** *(if used by the evaluation/model code)*
